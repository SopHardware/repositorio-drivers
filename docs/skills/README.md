# Skills - Boxito Development

Colección de skills para implementar el proyecto Boxito desde cero.

## Lista de Skills

| Skill | Descripción | Frameworks |
|-------|-------------|------------|
| [boxito-backend-api](./boxito-backend-api.md) | Backend API REST con Fastify | Fastify, TypeScript, JWT, Vitest |
| [boxito-admin-frontend](./boxito-admin-frontend.md) | Panel de administración | Next.js 14, React, Tailwind, Vitest |
| [boxito-public-frontend](./boxito-public-frontend.md) | Repositorio público | Next.js 14, React, Tailwind, Vitest |
| [boxito-database](./boxito-database.md) | Capa de datos con Prisma | PostgreSQL, Prisma ORM |
| [boxito-storage](./boxito-storage.md) | Almacenamiento con Google Drive | Google Drive API, Streams |

## Uso

Cada skill es independiente y puede seguirse de manera individual para aprender las técnicas específicas de cada capa del proyecto.

### Nivel
- **Intermedio**: Requiere conocimientos básicos de las tecnologías mencionadas.

### Enfoque
- **Independiente**: Cada skill se enfoca en una capa específica del proyecto.
- **Sin ejemplos reales**: Los skills contain código genérico sin dependencias del proyecto específico.
- **Testing incluido**: Cada skill incluye configuración y ejemplos de testing.

## Estructura de cada Skill

1. **Descripción**: Propósito y alcance del skill
2. **Pre-requisitos**: Tecnologías necesarias
3. **Técnicas de programación**: Guías por tema
4. **Testing**: Configuración y ejemplos
5. **Implementación paso a Paso**
6. **Links de referencia**

## Acerca del Proyecto

El proyecto **Repositorio de Drivers Boxito** es un sistema de gestión de drivers de hardware con arquitectura de triple capa:

- **Capa de Datos**: PostgreSQL + Prisma
- **Capa de Gestión**: Fastify (core-api)
- **Capa Pública**: Next.js (admin-portal + public-repo)

Para más información, consulta el [README principal](../../README.md).
